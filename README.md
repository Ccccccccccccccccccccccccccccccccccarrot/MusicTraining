# NoteTrainer

一个面向钢琴初学者的五线谱与听音训练 PWA。

## v0.1 功能
- 识谱模式：五线谱单音选择题
- 听力模式：播放单音后选择答案
- 每个模式每日默认 20 题
- 自适应权重：初始 0.50；答错 +0.05；答对 -0.05；范围 0.05~1.00
- 答错显示正确答案
- 听力错题支持“你的答案 / 正确答案”对比播放
- 高音谱号与低音谱号
- 可设置练习音域与每日题量
- localStorage 本地持久化
- PWA 离线缓存，可添加到 iPhone 主屏幕

## 部署
任何静态 HTTPS 托管均可。GitHub Pages、Cloudflare Pages、Netlify、Vercel 都可以。

> 注意：GitHub Pages 不支持直接从私有仓库免费公开托管的所有场景，具体取决于账号/计划。若要保持源码私有又公开访问，可用支持私有仓库连接的部署平台。

## iPhone
部署后用 Safari 打开站点，点击“分享” → “添加到主屏幕”。
