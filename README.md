# NoteTrainer

一个面向钢琴初学者的五线谱与听音训练 PWA。

## v0.2 功能

- 新增固定唱名显示，可在设置中切换为 `do、re、mi、fa、sol、la、si`
- 识谱训练的答题按钮使用裸唱名；听力训练、统计、音域与正确答案使用 `do₄、do₅` 等精确音组下标
- 新增“选项显示五线谱”复选框，同时作用于识谱与听力训练
- 启用后，四个答案以“迷你五线谱 + 当前文字标注”的形式显示；关闭后保持纯文字选项

## v0.1 功能

- 识谱模式：五线谱单音选择题
- 听力模式：播放单音后选择答案
- 每个模式每日默认 20 题
- 自适应权重：初始 0.50；答错 +0.05；答对 -0.05；范围 0.05~1.00
- 答错显示正确答案
- 听力错题支持“你的答案 / 正确答案”对比播放
- 高音谱号与低音谱号
- 可设置练习音域与每日题量
- localStorage 本地持久化
- PWA 离线缓存，可添加到 iPhone 主屏幕

## iPhone
可以用 Safari 打开站点，点击“分享” → “添加到主屏幕”。
